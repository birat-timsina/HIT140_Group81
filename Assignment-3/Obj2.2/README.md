# Data Sources and References — Objective 2.2

## Data sources

| Data | Source |
|---|---|
| Matches, scores, kickoff times, stage, venues | FIFA match API — https://api.fifa.com/api/v3/calendar/matches, https://api.fifa.com/api/v3/live/football/ |
| FIFA ranking points | FIFA World Ranking API — https://inside.fifa.com/api/ranking-overview |
| Elo ratings | World Football Elo Ratings — https://www.eloratings.net |
| Squads and player ages | Wikipedia API, *2026 FIFA World Cup squads* (10 June 2026 revision) — https://en.wikipedia.org/w/api.php |
| Squad market values | dcaribou/transfermarkt-datasets — https://github.com/dcaribou/transfermarkt-datasets; Transfermarkt API — https://www.transfermarkt.com |
| Stadium and capital altitudes | Open-Meteo Elevation API — https://api.open-meteo.com/v1/elevation |
| Match xG | The Stats Don't Lie — https://www.thestatsdontlie.com |
| Last 10 competitive matches per team | FIFA, UEFA, CAF, CONCACAF, AFC, CONMEBOL and OFC match reports |
| Team base camps | U.S. Soccer — https://www.ussoccer.com |
